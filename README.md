# Поиск фильмов 2.0 — лабораторная работа №6 (база + доп. задания)

Одностраничное приложение на React (Vite) + OMDb API. Базовая часть: поле ввода,
кнопка «Найти», карточки с постером, названием и годом, состояния загрузки / ошибки /
пустого результата, заглушка вместо отсутствующего постера, блокировка повторных
запросов.

Дополнительные задания (слайд 15 задания):

1. **Описание фильма** — для каждой карточки отдельный запрос `?i=<imdbID>`,
   отображается поле `Plot`, пока описание грузится — спиннер на карточке,
   ответы кэшируются в памяти, чтобы при пагинации не было повторных запросов.
2. **Пагинация** — параметр `page`, кнопки «Предыдущая / Следующая» и подпись
   «Страница N из M» (по 10 результатов на страницу, как отдаёт OMDb).
3. **Фильтрация по году** — поля «Год от / Год до», фильтрация текущей страницы
   на клиенте, при отсеве показывается «По фильтру: X из Y».
4. **История поиска** — последние 5 запросов в `localStorage`, выводятся чипами
   под поиском, по клику повторяют запрос, есть кнопка «Очистить».

Бонус из шага 7: автопоиск при вводе через `useEffect` + debounce 500 мс
(запрос уходит только после паузы, таймер очищается в `return`), плюс обычная
отправка по Enter и кнопке.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173).

## Ключ OMDb

1. Зайдите на https://www.omdbapi.com/apikey.aspx
2. Выберите **FREE! (1,000 daily limit)**, укажите email — ключ придёт на почту.
3. Впишите ключ в файл `.env`:

```
VITE_OMDB_API_KEY=ваш_ключ
```

4. Перезапустите `npm run dev` — Vite читает `.env` только при старте.

Без ключа приложение покажет понятную ошибку вместо падения.

## Как выполнены требования

| Требование | Реализация |
| --- | --- |
| Поле ввода + кнопка «Найти» | `<form onSubmit>` в `src/App.jsx`; круглая кнопка-лупа, работает и Enter |
| Карточка: постер, название, год | `src/MovieCard.jsx` |
| Состояния `idle / loading / error / success` | состояние `status` + отдельный `error` |
| «Ничего не найдено» | поле `Error` в ответе OMDb (`Movie not found!`) |
| Заглушка вместо постера | `Poster === 'N/A'` и `onError` → встроенный SVG-плейсхолдер |
| Запрет повторных запросов | кнопка `disabled` при `loading`, счётчик `requestId` отбрасывает устаревшие ответы |
| Уникальные `key` | `movie.imdbID` |
| Разбиение на компоненты | `App`, `MovieCard` |
| `useEffect` очищает таймер | debounce-эффект возвращает `clearTimeout` |
| Доп. 1: описание `?i=imdbID` | `fetchMoviePlot` в `src/omdb.js`, спиннер и кэш в `MovieCard.jsx` |
| Доп. 2: пагинация | `page` в `searchMovies`, `nav.pagination` в `App.jsx` |
| Доп. 3: фильтр по году | `yearFrom` / `yearTo` и `visibleMovies` в `App.jsx` |
| Доп. 4: история в `localStorage` | ключ `movie-search-history`, лимит 5, синхронизация эффектом |
